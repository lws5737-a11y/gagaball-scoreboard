# 진행 화면 보완 검증 기록

## 검증 환경

- 실제 Firebase가 아닌 `npm run preview:sample`의 가상 학생 26명 사용
- 브라우저 두 탭을 각각 스마트폰 리모컨과 TV 표시로 연결
- 스마트폰 화면 폭 390px 검증: 가로 넘침 없음
- 실제 학생 명단·점수·배포 설정 변경 없음

## 확인한 흐름

- 같은 추첨 선수와 개인 점수를 TV에서 표시
- 점수 연속 증가, 되돌리기, 저장 이후 새로고침으로 기록 유지
- 새로고침 직후 첫 변경이 서버 기준본을 오염시키던 문제 수정 후 회귀 검증
- 4팀 편성, 3팀 대 4팀만 표시, 이전 선수 결과 창 닫기
- 팀 미션 결과 전달, 개인전 미션 결과 3초 하이라이트 이후 자동 닫기
- 60초·100초 시작, 일시정지 전달, 종료 상태 유지
- 같은 탭의 연결 복원 및 만료 후 새 코드 연결
- 스마트폰 화면에서 이미지 없는 텍스트·터치 조작

## 자동 검사

`npm test`: 48개 테스트 통과. 기존 순위·심판 배치·아바타·음원 경로·현상수배 테스트에 다음 회귀 검사를 추가했습니다.

- 동시 점수 가산 병합 및 저장 중 추가 클릭 보존
- 명단 수정 충돌 감지와 학급 삭제 보존
- 서버 저장 완료 후 응답을 잃어도 같은 쓰기 재시도로 중복 가산하지 않음
- 서버 기준본과 화면 편집 객체 분리
- 미지정 성별 학생을 팀에서 빠뜨리지 않음
- 팀 점수 0에서 빼기를 눌러도 개인 점수가 줄지 않음
- 점수 버튼의 키보드 입력이 현상수배 효과로 전달되지 않음
- 타이머 경과 시간과 백업 입력 검증
- 연결 정보가 아직 도착하지 않은 새로고침 순간의 상태 표시

JavaScript 구문 검사와 Git diff 공백 검사도 수행했습니다.

## 배포 전 실제 기기 점검 필요

- 실제 승인 교사 계정의 Firestore 읽기·트랜잭션 쓰기 권한
- 교실 TV 연결 PC와 Android/iPhone 조합의 오디오 허용, 음량, 실제 스피커 출력
- Wi-Fi·모바일 데이터 환경의 전송 지연과 재연결
- 두 기기의 날짜·시간 자동 설정, 화면 잠금과 절전 설정
- 백업 파일을 내려받은 뒤 실사용을 시작할 것

공유 문서 구조와 현재 보안 규칙은 유지합니다. 연결 코드는 별도 권한 분리 수단이 아니며, 승인 교사 간 데이터 격리는 구현하지 않았습니다. 완전한 오프라인 설치형 앱도 이번 범위에 포함하지 않습니다.
