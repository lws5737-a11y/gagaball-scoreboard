# 동산초 가가볼 콜로세움

교실 체육 수업에서 가가볼 참가자 추첨, 개인·팀 점수, 명예의 전당과 도장판을 관리하는 웹 앱입니다.

배포 주소: <https://dongsan-gagaball.vercel.app/>

## 로컬 확인

정적 파일 서버로 프로젝트 루트를 열어 사용합니다. JavaScript 검사는 다음 명령으로 실행할 수 있습니다.

```sh
npm run check
npm test
```

실제 학생 데이터에 접근하지 않는 샘플 화면은 `npm run preview:sample`로 실행한 뒤 `http://127.0.0.1:4173`에서 확인합니다. 이 서버는 메모리에 저장한 가상 학생 26명만 사용하며 Firebase 로그인·저장을 대체합니다. 서버를 종료하면 샘플 서버 기록은 사라집니다. 개발 검증 전용이며 외부에 공개하지 마세요.

## 스마트폰 진행 화면과 TV 리모컨

오른쪽 아래 **진행 도구**에서 화면 모드를 선택합니다. 처음 접속한 좁은 화면은 스마트폰 단독 모드가 기본입니다.

- **스마트폰 단독**: 큰 터치 버튼과 텍스트 중심으로 선수 추첨, 심판 지정, 왕중왕전, 팀 편성, 왕 지정, 점수, 미션, 60·100초 타이머를 조작합니다. 아바타와 배경을 표시하지 않습니다. 소리는 스마트폰에서 재생합니다.
- **TV 표시**: 기존 그림·아바타·연출을 유지합니다. 팀별 `이 경기 보기`로 1·2팀 또는 3·4팀 경기만 크게 볼 수 있습니다.
- **스마트폰 리모컨**: 스마트폰에서 조작하고 TV에서 결과와 소리를 재생합니다. 스마트폰 소리는 중복되지 않도록 음소거합니다.

연결 순서:

1. TV에 연결한 PC의 브라우저와 스마트폰에서 같은 승인된 교사 계정으로 로그인합니다.
2. TV의 진행 도구에서 `TV 연결 코드 만들기`를 누릅니다. 소리가 막히면 TV에서 `소리 켜고 시작`을 한 번 누릅니다.
3. 스마트폰 진행 도구에서 TV의 4자리 코드를 입력하고 `리모컨 연결`을 누릅니다.
4. 스마트폰에서 학급을 선택하고 진행합니다. 연결 중에도 PC/TV에서 점수·타이머·추첨 등을 직접 조작할 수 있으며 양쪽 화면에 반영됩니다. 서로 다른 경기 진행 명령을 동시에 입력하면 마지막으로 서버에 반영된 화면 상태를 따릅니다. `TV 적용 완료`로 전달 여부를 확인합니다.
5. 수업 후 `연결 해제`를 누릅니다. 연결은 최대 4시간 동안 유효합니다.

창을 닫은 연결은 양쪽 기기가 2분 이상 응답하지 않으면 다음 연결 작업에서 자동 정리합니다. 연결 한도가 찼을 때에는 같은 교사 계정의 리모컨 미연결 대기 기록도 정리합니다. 그래도 연결 안내가 나오면 진행 도구의 `미사용 TV 연결 정리`를 누른 뒤 다시 연결하세요. 현재 기기의 연결과 응답 중인 TV·리모컨 쌍은 유지합니다.

같은 Wi-Fi가 아니어도 양쪽 인터넷 연결이 필요합니다. 연결 코드는 한 대의 리모컨이 제어하도록 하는 장치이며, 별도의 계정 간 보안 경계는 아닙니다. 기존 승인 교사들이 공유 문서에 접근하는 권한은 그대로입니다. 원격 상태는 기존 문서의 `gagaRooms`에 저장되므로 별도 서버나 새 Firestore 컬렉션은 필요하지 않습니다. 연결 중에는 10초 간격 상태 확인과 조작별 읽기·쓰기가 발생합니다.

브라우저 새로고침 시 같은 탭의 유효한 연결을 복원합니다. 상대 기기가 30초 넘게 응답하지 않으면 리모컨 조작을 막고 연결 확인을 안내합니다. 네트워크 지연은 있을 수 있으며 타이머는 시작 시각을 공유해 경과 시간을 계산합니다. 두 기기의 날짜·시간 자동 설정을 켜고, 수업 전에 실제 TV와 스마트폰으로 소리·지연을 확인하세요. 화면 잠금·절전·백그라운드 전환은 브라우저 실행을 지연시킬 수 있습니다.

## 저장과 복구

- 저장 중인 동안 이어서 누른 점수도 다음 저장에 반영합니다. 동시 점수 변경은 증가·감소량을 합치고, 충돌하는 명단 수정은 덮어쓰지 않고 오류로 알립니다.
- 쓰기 식별자로 저장 재시도에 의한 중복 가산을 방지합니다.
- `되돌리기`는 현재 탭에서 수행한 최근 15개 명단·점수 변경을 지원합니다. 새로고침하면 되돌리기 목록은 초기화됩니다.
- 저장 실패 시 `저장 재시도` 또는 `미저장 임시본 내려받기`를 사용합니다. 저장 충돌은 임시본을 보관하고 `서버 기록 다시 불러오기`로 최신 상태를 확인하세요.
- 변경 전 안전 백업과 수동 JSON 백업·복원을 제공합니다. 백업에는 학생 이름과 점수가 포함되므로 외부 공유에 주의하세요.
- 단독 모드의 경기 상태는 기기에 보관하며, 새로고침 후 타이머는 일시정지 상태로 복구합니다. 최초 접속·로그인까지 보장하는 완전한 오프라인 앱은 아닙니다.

TV 글자 확대, 순위 5열 고정, 순위 전환 6초·10초·수동은 진행 도구에서 선택할 수 있습니다.

## 자체 카운트다운 타이머

60초·100초 타이머는 유튜브 연결 없이 저장소의 MP3와 일러스트를 사용합니다. 같은 음높이의 짧은 레이스 신호 3회와 더 높고 긴 출발 신호가 나온 뒤 경기 시간을 재며, 마지막 10초를 영어 심판 음성으로 읽고 0초에 폭발 종료음을 냅니다. 화면과 음원은 공통 경과 시간에 맞추며, 음원 재생이 차단되어도 무음 타이머는 계속 진행합니다. 일시정지·재시작·위치 조절·전체 화면도 지원합니다.

완성된 음원은 `sound/countdown-60s.mp3`, `sound/countdown-100s.mp3`입니다. 배경 그림은 `images/gagaball-colosseum-timer.png`와 모바일용 `images/gagaball-colosseum-timer-mobile.png`입니다. 카운트다운 음성과 자체 합성한 출발·폭발 효과를 사용하며, 원곡은 카운트다운 중에도 인위적으로 음량을 낮추지 않습니다. 다시 제작하려면 원본 `Colosseum Clash.wav`와 Python의 `numpy`, `edge-tts`, `imageio-ffmpeg`가 필요하며 `scripts/generate-wild-timer-voices.py`, `scripts/build-colosseum-clash-preview.py`를 사용합니다. 저장된 완성 MP3를 재생할 때에는 이 도구들이 필요하지 않습니다.

## Firestore 보안 설정

`firebaseConfig`의 API 키는 웹 앱 식별값이며 비밀번호가 아닙니다. 학생 명단 보호는 Firestore Security Rules가 담당합니다.

저장소의 `firestore.rules`는 `authorizedTeachers/{uid}` 문서가 있는 Google 로그인 사용자만 공용 학급 문서를 읽고 수정하도록 구성한 권장 규칙입니다.

적용 전 Firebase Authentication에서 교사 UID를 확인하고, Firebase Console의 Firestore에 다음 빈 문서를 관리자 권한으로 생성합니다.

```text
authorizedTeachers/<교사 UID>
```

그다음 Firebase Console의 Rules 화면에 `firestore.rules` 내용을 붙여 넣어 게시합니다. 교사 UID 문서를 먼저 만들지 않고 규칙을 게시하면 모든 사용자가 앱 데이터에 접근할 수 없으므로 순서를 지켜야 합니다.

## 데이터 주의사항

- 학급 데이터는 현재 하나의 공용 문서에 저장됩니다.
- 여러 번 빠르게 누른 같은 브라우저의 쓰기는 순서대로 저장됩니다. 다른 기기의 독립 변경은 트랜잭션에서 병합합니다.
- 학교 전체 문서에 학급·학생·연결 상태가 함께 있으므로 규모가 커지면 학급·학생·연결별 문서 분리와 서버 수준 연결 소유자 검증이 필요합니다. 현재 연결 코드를 보안 기능으로 간주하지 마세요.
